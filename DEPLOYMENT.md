# Deploy ke Streamlit Community Cloud

1. Buka [share.streamlit.io](https://share.streamlit.io) dan masuk dengan GitHub.
2. Pilih **Create app** lalu **Yup, I have an app**.
3. Isi:
   - Repository: `Tuagus23/FIS-MAMDANI-GWO-`
   - Branch: `main`
   - Main file path: `app.py`
4. Klik **Deploy**. Streamlit akan memberikan URL `*.streamlit.app`.

Repo ini bersifat publik, sehingga aplikasi akan publik secara default dan siapa pun dapat melihatnya. Streamlit juga dapat mengindeks aplikasi publik di mesin pencari. Jika akses perlu dibatasi ke rekan tertentu, ubah pengaturan **Sharing** aplikasi dan undang mereka; perlu diingat kode sumber di repo ini tetap publik. Simpan kode di repo privat bila kode juga harus dibatasi.
