# Fuzzy CH WSN interface

This polish preserves the dashboard's established forest green identity, Indonesian language, scientific charts, and the group's supplied photos and motto. The audience is classmates and lecturers comparing simulation results. The requested direction is simple, elegant, modern, and easy to read.

## Visual direction

- Forest green navigation anchors the product; a light neutral canvas and white panels keep dense data legible. Protocol colors and symbols keep their established meanings.
- Manrope is the interface face: clear counters and a consistent variable weight range suit controls and dense labels. Tabular figures align measurements. The motto retains its existing serif and condensed display faces.
- Use a 4px spacing rhythm, with 24–32px between content groups and 16–24px inside panels. Keep related controls together and separate the dataset context from account controls.
- Shared panels use a 1px boundary and 14px radius. No decorative elevation. Numerical summary belongs to one continuous strip, with separators for comparison.
- Navigation groups reflect analysis, algorithm exploration, and group information. Initials identify the signed-in account using the real server-provided name.

## Motion

Purpose: state indication and continuity while moving through data. ENERGY 2 / RHYTHM 3 / MOTION 2.

- Lenis and GSAP share one animation ticker for the dashboard lifetime, with native touch scroll and full cleanup.
- A pointer-initiated route entrance lasts 200ms with the existing strong ease-out. Keyboard navigation changes immediately.
- Below-fold panels reveal once when scrolling; their data remains visible by default. Hover only changes control feedback and panel boundary, without scaling charts or moving data under the pointer.
- Reduced motion removes spatial transitions. No loops beyond a truthful pending indicator.

## Data-reading refinements

- The top bar uses a pale forest tint to separate navigation and account context from white data panels; secondary text is darkened for contrast on the tint.
- Glossary terms receive a dedicated column wide enough for Indonesian multiword terms. Tables keep tabular figures, sticky headers inside scrollable details, keyboard focus, and a visible native scrollbar.
- Membership cards align at their top edges and size independently when their data disclosures open.
- Validation conclusions show actual FUZZY, tie, and GWO seed counts as labeled segments. These are source data, not decorative progress indicators.
- The fitness chart uses an explicitly disclosed focused Y range and four decimal places so the observed small changes remain readable without altering their values.
- FIS inputs, input memberships, aggregated output, and active rules are grouped by the calculation sequence. Input edits update the existing chart instance immediately; invalid drafts show a recovery message rather than a stale score.
- The motto has the one authored typographic moment: a single 250ms word entrance with 60–80ms staggering, followed by static readable text. Purpose: delight on this occasional group page. Keyboard navigation is immediate and reduced motion keeps opacity only. The supplied image and network diagram remain in place.
- The small curved arrow beside the motto image labels the existing user-requested Easter egg; it does not create a new action.

## Layout consistency

- Shared page stacks use 24px spacing (20px on phones), with one heading scale and 14px body/control text; supporting information stays at least 13px.
- Content width is capped at 1440px. Container queries respond to the actual reading area beside the sidebar, so MF comparisons, seed tables, team profiles, and simulation results receive useful widths rather than following viewport width alone.
- MF comparisons keep before and after side by side when space permits, with larger plotting areas; disclosures expand each variable independently.
- Table headers may wrap, while numerical cells keep tabular figures and right alignment. Text columns explicitly align left and long descriptions wrap inside their own column.
- Team portraits share a crop and body spacing; compact layouts place the photo beside readable identity and responsibility text. The group heading replaces the duplicate introductory heading.
- Simulation parameters align their fields and helpers; results receive the larger column and stack cleanly on narrow screens. Charts and original data retain their existing meaning.

## Boundaries

Do not change experiment data, algorithm math, access rules, CSV meaning, or supplied group identity as part of visual polish. Use the existing photos and diagrams; add no invented claims or statistics.
